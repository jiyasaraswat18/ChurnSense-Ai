# ChurnSense AI – Machine Learning Module

The Machine Learning module of **ChurnSense AI** is responsible for developing, training, and optimizing the predictive model used to identify customers who are at risk of churning. This module covers the complete machine learning lifecycle—from raw data preprocessing and exploratory analysis to model training, evaluation, feature importance analysis, and deployment-ready model serialization.

The trained model generated by this module is consumed by the backend service to perform real-time customer churn predictions.

---

# Module Responsibilities

This module is responsible for:

- Loading and preprocessing the customer churn dataset
- Performing exploratory data analysis (EDA)
- Cleaning and transforming raw data
- Engineering features suitable for model training
- Building a reusable preprocessing pipeline
- Training and comparing machine learning models
- Optimizing model performance using hyperparameter tuning
- Evaluating model performance using multiple classification metrics
- Identifying the most influential features affecting churn prediction
- Exporting the trained model for backend integration

# Dataset

The model is trained using an e-commerce customer churn dataset containing customer demographics, purchasing behaviour, engagement metrics, and satisfaction-related information.

The prediction target is:

```
Churn

0 → Customer Retained

1 → Customer Churned
```

The dataset includes features related to:

- Customer demographics
- Login behaviour
- Purchase history
- Payment preferences
- Customer tenure
- Device usage
- Order frequency
- Cashback amount
- Complaint history
- Customer satisfaction
- Shipping preferences
- Order intervals

These features collectively enable the model to learn behavioural patterns associated with customer attrition.

---

# Data Preprocessing

Real-world datasets often contain inconsistencies that must be addressed before model training. The preprocessing pipeline ensures that the data is transformed into a suitable format for machine learning algorithms while maintaining consistency between training and inference.

The preprocessing workflow includes:

- Handling missing values
- Removing duplicate records
- Separating numerical and categorical features
- One-Hot Encoding categorical variables
- Numerical feature transformation where required
- Train-test splitting
- Building a preprocessing pipeline using Scikit-Learn's `Pipeline` and `ColumnTransformer`

The preprocessing pipeline is serialized together with the trained model, ensuring identical transformations are applied during prediction.

The analysis includes:

# Model Development

Several classification algorithms were evaluated during experimentation before selecting the final production model.

The final deployed model is:

## XGBoost Classifier

XGBoost was selected because it provides:

- High predictive accuracy on structured datasets
- Excellent handling of non-linear feature interactions
- Built-in regularization mechanisms
- Efficient gradient boosting implementation
- Strong generalization performance

The model is trained using the Scikit-Learn API, making it easy to integrate with preprocessing pipelines and deployment workflows.

---

# Hyperparameter Optimization

To improve model performance beyond default settings, hyperparameter tuning was performed using **GridSearchCV**.

Parameters such as:

- Number of estimators
- Learning rate
- Maximum tree depth

were systematically optimized to identify the best-performing configuration.

### Best Cross-Validation Score

```
0.96
```

The optimized model was selected as the final production model.

# Model Evaluation

The trained model was evaluated using multiple classification metrics to ensure balanced performance.

Evaluation metrics include:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Score
- Confusion Matrix

Using multiple evaluation metrics provides a more comprehensive understanding of model performance than relying solely on accuracy.

# Feature Importance Analysis

Model interpretability is an important aspect of machine learning systems.

Feature importance analysis was performed using XGBoost's Gain-based importance scores to determine which customer attributes contribute the most toward churn prediction.

The notebook includes:

- Ranked feature importance table
- Top 10 most influential features
- Feature importance visualization

These insights help explain model behaviour and support business decision-making.

---

# Model Serialization

After training and evaluation, the complete preprocessing pipeline and trained XGBoost model are exported using **Joblib**.

```
Model/
└── churn_model.pkl
```

Saving the complete pipeline ensures that:

- identical preprocessing is applied during inference,
- manual feature transformation is unnecessary,
- deployment becomes significantly simpler,
- prediction results remain consistent with the training workflow.

# Backend Integration

The backend loads the serialized model using Joblib.

```python
import joblib

model = joblib.load("../Model/churn_model.pkl")
```

Incoming customer data is passed directly to the serialized pipeline. The pipeline automatically applies all preprocessing steps before generating churn predictions, eliminating the need for manual data transformation in the backend.
